# 💼 Employee Salary Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting employee salary levels (≤50K or >50K) using machine learning techniques. The model is trained on the Adult Income dataset and aims to analyze how factors such as age, education, occupation, working hours, and capital gains influence income levels.

The project was developed as part of an **Artificial Intelligence & Machine Learning internship** under the **AICTE – Edunet Foundation program**.

---

## 🎯 Objective

* To build a machine learning model that predicts employee income category
* To apply proper data preprocessing and feature engineering techniques
* To evaluate model performance using standard classification metrics

---

## 🗂 Dataset

* **Dataset Name:** Adult Income Dataset
* **Target Variable:** Income (≤50K or >50K)
* **Type:** Structured tabular data

---

## ⚙️ Methodology

1. Loaded and explored the dataset
2. Handled missing values and cleaned data
3. Encoded categorical features using Label Encoding
4. Scaled numerical features using StandardScaler
5. Split data into training and testing sets
6. Trained a Random Forest Classifier
7. Evaluated the model using accuracy, confusion matrix, and classification report
8. Visualized insights and feature importance

---

## 🤖 Machine Learning Model

* **Algorithm Used:** Random Forest Classifier
* **Type:** Supervised Learning (Classification)
* **Reason:** Handles non-linear relationships well and provides feature importance

---

## 📊 Model Evaluation

* Accuracy Score
* Confusion Matrix
* Precision, Recall, and F1-Score

The model achieved good accuracy and demonstrated strong performance in distinguishing income categories.

---

## 📈 Visualizations

* Income distribution
* Age vs income
* Education level vs income
* Working hours vs income
* Capital gain and capital loss analysis
* Feature importance plot

---

## 🧪 Technologies Used

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Visualization:** Matplotlib, Seaborn
* **Platform:** Google Colab / Jupyter Notebook

---

## 🔍 Key Insights

* Dataset is imbalanced with more individuals earning ≤50K
* Higher education, age, working hours, and capital gains correlate with higher income
* Capital gain is one of the strongest predictors of income
